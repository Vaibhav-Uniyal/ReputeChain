# ReputeChain Frontend

Modern React UI for interacting with the ReputeChain smart contract.

## Features

- 🔐 MetaMask wallet connection
- 👤 Search researcher profiles
- 📊 Real-time reputation dashboard
- 📝 Registration portal
- 💰 Token tracking

## Setup

```bash
cd frontend
npm install
npm start
```

## Environment Variables

Create a `.env` file:

```
REACT_APP_CONTRACT_ADDRESS=0x5FbDB2315678afecb367f032d93F642f64180aa3
```

## Build

```bash
npm run build
```
